# Contributing

Describe the behavior being changed, include a small reproduction or expected result, and run the checks in the README before opening a pull request. Keep generated logs, datasets, build directories and machine-specific settings out of new commits.

Report which checks actually ran and which need hardware or a desktop display. Performance claims should include the scenario, input data, tool versions and measurement method.

No open-source license has been selected. The owner and any coauthors should agree on licensing before adding a license. A public repository alone does not grant a reuse license.
